# samples

開発・テスト・デモ用のダミーデータです。商品・メーカー・生協の名前、価格、原材料はすべて架空で、実在の商品・企業・団体とは関係ありません。実物のチラシやパッケージの画像は置きません。

| フォルダ | 中身 |
| --- | --- |
| `flyers/` | 架空のチラシ（画像・撮影風の画像・PDF）と、読み取りの正解データ（`*.expected.json`） |
| `packages/` | 架空のパッケージ（表面と原材料表示の面の画像）と、アレルゲン抽出の正解データ（`*.expected.json`） |

## チラシ

| チラシ | 中身 |
| --- | --- |
| `flyer-01` | せんべい・あられ・豆菓子（16商品） |
| `flyer-02` | チョコレート・ビスケット・スナック（20商品）。デモの山場（下記）を載せる。E2E で主に使い、取り込みの分類（下記）にそれぞれ当たる商品を入れている |
| `flyer-03` | 冷蔵デザート（8商品）。説明文が番号・価格の上にあり、アレルゲンは「［卵・乳］」と角括弧で書く |

どのチラシも、生協のお菓子のページの書き方に寄せて、読み取りでつまずきやすいところを再現しています。商品・メーカー・価格・内容量・説明文は架空で、書き方だけを似せています。

- アレルゲンは特定原材料だけを略して書く（「（卵・乳・麦・え）」の麦＝小麦、え＝えび、か＝かに、落＝落花生、く＝くるみ、カ＝カシューナッツ）。ひらがなの「か」（かに）とカタカナの「カ」（カシューナッツ）は字で分ける（FR-IMPORT-32）。アーモンド・ごま・大豆などは説明文にあっても表記に出ない
- 3桁と4桁の注文番号が混ざる。次回予定は「12月1回」のように「回」で書く
- 「1袋/本体48円」のような1個あたりの単価の行、「くらし応援」の赤い枠の価格、「今回より値上げ」「○○部門 1位」の帯、「人気ベスト1」の印
- 「冷蔵」の印、次回予定の代わりの「毎週」、空欄の次回予定、「※はちみつ使用。」「※洋酒使用。」の注意書き
- 撮影風の画像は、上半分・下半分（`*-photo-top.png`・`*-photo-bottom.png`）と、1ページを丸ごと斜めから撮ったもの（`*-photo-full.png`）

デモデータ（`DemoDataSeeder.cs`）の商品と、同じ商品・味違い・内容量違いになる商品を混ぜています（照合の確認用）。D-100 から、照合は正規化した「商品名＋メーカー」の完全一致だけです（[09. チラシ取り込みの分類](../docs/requirements/09-flyer-import.md)）。そのため、`_trap` の「味違い」（名前が違う商品）は一致せず、別の商品（新しい商品として「要確認」）になります。「内容量違い」（名前＋メーカーが同じで内容量が違う商品）は同じ商品として一致し、マスタとチラシの内容量・入数を職員が確かめる「再入力」になります。似ている商品を AI で判定する仕組みはなくしました。

### 取り込みの分類に当たる商品（flyer-02）

デモデータはナッツ類（すべて）を避けています。それを前提に、`flyer-02` には取り込みの分類のそれぞれに当たる商品を入れています（E2E で確かめる。表は `src/oyatsubiyori.client/e2e/README.md` にも）。

| 分類 | 商品 |
| --- | --- |
| 使えない | 8110 うすしお ポテトチップス 大袋（入数が分からない）・427 こつぶ しお豆スナック（「（乳・カ）」のカ＝カシューナッツ） |
| 再入力 | 8102 CO・OP さくさくクッキー（登録済みと同じで内容量が違う）・428 ふんわり 抹茶ロール（税込価格が読めない）・8121 にこにこ ミニドーナツ（メーカーがない） |
| 要確認 | 8104 ことりのさくさくショコラ・8101 CO・OP ポテトチップス のりしお（味違い）・8105 ことりのピピ ラムネ（表記なし）など、一致する商品がないもの |
| 使える | 8103 くまのポッケ ミルクビスケット（登録済みと同じ） |
| 外した掲載品 | 429 キッチン スポンジ 3個（食品以外） |

元データ（`flyers/*.json`）では、次の印で読み取りにくい商品を作ります（`tools/build-samples/build.py`）。

| 印 | チラシ | 正解データ |
| --- | --- | --- |
| `"maker": null` | メーカーの行を描かない | `maker` が null（メーカーが読めない） |
| `"priceUnreadable": true` | 税込価格をかすれさせて描く | `priceIncludingTax` が null（税込価格が読めない） |
| `"nonFood": "理由"` | ほかの商品と同じに描く | `nonFood: true` と `nonFoodReason`（食品以外の掲載品） |

各商品の `_trap`（元データと正解データ）に、その商品で確かめたいことを書いています。

## 作り直し方

元データは `flyers/*.json` と `packages/*.json` です。直したら、次のコマンドで画像・PDF・正解データを作り直します（Edge か Chrome が必要）。

```
python tools/build-samples/build.py
```

`*.expected.json`・画像・PDF・`flyers/*.html` は生成物なので、直接編集しません。

## デモの山場

チラシ `flyer-02` の「8104 ことりのさくさくショコラ」は、原材料にヘーゼルナッツペーストを含みますが、チラシには探す言葉が出てきません（このチラシにナッツの言葉を出すと生成が止まります）。同じチラシに「（乳・カ）」（カシューナッツ）の商品がありますが、チラシに印刷されるのは略記の「カ」だけです（生成の確かめは、略記を品目名で書いた元データの `allergenLabel` を除いて見ます）。取り込み直後は「参考」の警告で献立に入り、パッケージの原材料表示（`packages/package-8104-back.png`）で初めて見つかります。
