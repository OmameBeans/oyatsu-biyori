# 座標・間隔・線の引き方

キャンバスは絶対配置の座標系（幅・高さは必要なだけ。既定 1256×546）。画面ノードは `position:absolute` の div、遷移の線はキャンバスと同じ大きさの SVG 1枚に描く。すべて手で置くので、下のルールが「線が文字を横切らない」ことを保証する。

## 画面ノードの箱

```
left = 中心X - 88               （.screen の幅は 176、文字は中央ぞろえ）
frame：PC 160×100（中心X±80）／スマホ 56×100（中心X±28）。上端 = top
名前：top+108 から（12.5px、1行）
サブ（URL など）：top+128 から（9.5px 等幅）
箱の下端 ≈ top + 144
```

1画面は **176 × 144** の箱として扱う。名前は全角12文字程度まで（それ以上は2行になり、箱の下端が +162 になる。並びの間隔を広げるか、名前を短くする）。

## 間隔

- 横：同じ行の中心どうしは **200 以上**（ラベルのない線）、**240 以上**（ラベルのある線。frame の間が 80 空き、全角5文字ほどのラベルが入る）
- 縦：行の frame 上端どうしは **220〜230**（下の行との間に 76〜86 空く。縦の線のラベルはここに入る）
- グループの左右：いちばん外の画面の中心 **±112**（箱の端から 24 外）。左右の余白をそろえる
- グループの上下：上端 = 最初の行の frame 上端 − 56（ラベルの帯）、**下端 = 最後の行の frame 上端 + 168**
- 入れ子のグループ（タブ・手順）：親から左右・下に 24 以上内側、親の上端から **44 以上下**（親のラベルの下）
- 並んだ2つのグループ（例：ログイン不要と、ログイン後）の間は 24
- キャンバスの外周は 24 以上空ける。入口の ● を左に置くなら、最初のグループの左端を 40 にする

## 線の端点 — 文字を横切らないためのルール

**画面は frame とその下の文字のセット。** 線は `(中心X±88, top..top+144)` の箱の境界につなぐ。

- **横の線**（同じ行）：frame の中段 `y = top+50` で、frame の横から横へ。PC は `中心X+86 → 相手の中心X−86`、スマホは `±34`（frame 幅 ±28 に 6 の隙間）。frame の横には文字がないので安全
- **縦の線**（上下の行）：**上の箱の下端 → 下の frame 上端**。`y = 上のtop+150` から `y = 下のtop−6` まで（上向きなら逆）。frame の下端（top+100）から出すと名前を突き抜けるので禁止
- **折れ線**（行も列も違う）：縦の部分は画面の箱がない x の通り道を、横の部分は行と行の間の帯（`下の行のtop−56 .. top−10`）か frame の中段を通す。線どうしの交差はかまわないが、**画面の箱を横切らない**
- 線の端と境界のあいだは 4〜6 空ける。矢じり（marker）が届く
- **グループから出る線** ＝「その枠の中のどの画面からでも」（例：未ログインならログインへ）。グループの枠線から出す。グループのラベルの角は避ける
- **グループに入る線** ＝ その枠の代表の画面（タブなら最初のタブ、手順なら手順1）を指す

## 線の種類とラベル

```html
<circle class="start" cx="22" cy="150" r="5"/>                         入口（●）
<path class="e" d="M238 150 H358" marker-end="url(#ar)"/>              主な流れ（色つき実線）
<path class="n" d="M726 150 H794" marker-end="url(#ar)"/>              遷移（灰色の実線）
<path class="n dash" d="M528 400 H392 V250" marker-end="url(#ar)"/>    条件つき・自動（破線）
<path class="n" d="M972 150 H1028" marker-start="url(#ar)" marker-end="url(#ar)"/>  往復（両矢印）
<text class="el a" x="298" y="142" text-anchor="middle">ログイン</text>  ラベル（主な流れは el a）
```

- 主な流れは **1本のつながった道** にする（入口 → … → 目的の画面）。そこから外れる遷移は灰色
- ダイアログ・タブの切り替えのように「行って戻る」ものは両矢印1本にまとめる（2本引かない）
- 横の線のラベル：線の上、`y = 線のy − 8`、x は線の中央
- 縦の線のラベル：線の右、`x = 線のx + 10`、y は線の中ほど
- 平行な線が近くに並ぶときは、ラベルを「その線にしかない部分」（片方だけの横の区間など）に置く。2本の間に置くと、どちらの線のラベルか分からなくなる
- ラベルはボタン名やきっかけを全角2〜6文字で（「献立を作る」「未ログイン」）。詳しい条件は遷移一覧の表に書く
- 矢じりは `#ar` の1つだけ。`context-stroke` で線と同じ色になるので、色ごとに作らない

## 作例（テンプレートのサンプル）

キャンバス 1256×546。1行目の frame 上端 = 100。
ランディング（中心 152, PC）、ログイン（中心 392, スマホ）、一覧（640）、詳細（880）、編集ダイアログ（1120）。2行目 = 330：設定のタブ 一般（664）、通知（864）。

```
グループ「ログイン不要」  left:40  top:44  w:464 h:224   （152−112 → 392+112、100−56、100+168）
グループ「ホーム」        left:528 top:44  w:704 h:478   （640−112 → 1120+112、下端 = タブの枠の下端+24）
入れ子「設定（タブ）」    left:552 top:274 w:424 h:224   （664−112 → 864+112、330−56、330+168）
入口        ● (22,150) → M28 150 H66          （ランディングの frame 左 72 − 6）
LP→ログイン  M238 150 H358                    （152+86 → 392−34。相手がスマホなので ±34）
ログイン→一覧 M426 150 H554                    （392+34 → 640−86）
未ログイン   M528 400 H392 V250                （ホームの枠 → ログインの箱の下端 244+6）
```

置いたら、縦・折れ線の部分をすべて書き出し、「この x の通り道は y1〜y2 のあいだにどの画面の箱を通るか」を確かめる。答えは「なし」でなければならない。
