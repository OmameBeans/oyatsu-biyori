# samples

開発・テスト・デモ用のダミーデータです。商品・メーカー・生協の名前、価格、原材料はすべて架空で、実在の商品・企業・団体とは関係ありません。実物のチラシやパッケージの画像は置きません。

| フォルダ | 中身 |
| --- | --- |
| `flyers/` | 架空のチラシ（画像・撮影風の画像・PDF）と、読み取りの正解データ（`*.expected.json`） |
| `packages/` | 架空のパッケージ（表面と原材料表示の面の画像）と、アレルゲン抽出の正解データ（`*.expected.json`） |

## 作り直し方

元データは `flyers/*.json` と `packages/*.json` です。直したら、次のコマンドで画像・PDF・正解データを作り直します（Edge か Chrome が必要）。

```
python tools/build-samples/build.py
```

`*.expected.json`・画像・PDF・`flyers/*.html` は生成物なので、直接編集しません。

## デモの山場

チラシの「8104 ことりのさくさくショコラ」は、原材料にヘーゼルナッツペーストを含みますが、チラシには探す言葉が出てきません（出すと生成が止まります）。取り込み直後は「参考」の警告で献立に入り、パッケージの原材料表示（`packages/package-8104-back.png`）で初めて見つかります。
