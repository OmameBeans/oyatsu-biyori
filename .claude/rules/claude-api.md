# Claude 呼び出しの決まり（OyatsuBiyori.Claude）

C# の書き方は [csharp.md](csharp.md) に従う。ここでは Claude を呼ぶコードとプロンプトの決まりを書く。用途の一覧は [02 §9](../../docs/requirements/02-functional.md)。

## 呼び出し

- 公式 C# SDK（NuGet の `Anthropic`）を使う
- モデル名・API キーは設定から読む。コードに直書きしない（API キーは `dotnet user-secrets` か環境変数 `ANTHROPIC_API_KEY`。既定のモデルは `claude-sonnet-5-5`）
- タイムアウトと、回数を限った再試行を設ける（NFR-OPS-04、D-64）。値は設定から読む（仮の値：画像の読み取りと献立は90秒、照合の判定は30秒。再試行は2回まで）
  - SDK の自動の再試行は切り（`MaxRetries = 0`）、アプリ側で再試行する。1日の呼び出し回数の上限は、失敗・再試行も含めて1回ごとに数えるため（D-65）
  - 処理全体の期限は `CancellationToken` で受ける。期限はタイムアウトと再試行の合計より長くし、期限が近ければ再試行しない
- 失敗したら `Result` のエラーとして返し、画面から再試行できるようにする
- Claude API が止まっていても、商品一覧・献立の閲覧・手動での献立編集は動くようにする（NFR-OPS-03）。Claude を使わない処理から、この層に依存させない

## 出力の受け取り

- 結果は構造化出力（JSON スキーマ）で受け取ってデシリアライズする（D-04）。形が崩れていたら `Result` のエラーにする
- 受け取った値はアプリ側で検証してから使う。Claude が存在しない商品、今週のチラシに載っていない商品、候補から外した商品（「今週は使わない」「使わない」「対象外」。D-52）を返したら、その商品は採用せずエラーとして差し戻す（検証の中身は [biz-logic.md](biz-logic.md) の「献立案の検証」）
- 金額・人数・予算・アレルゲンの判定は Claude の出力を使わず、Biz で計算する（[biz-logic.md](biz-logic.md)）
- アレルゲンの判定結果は「候補」として返す。「確認済み」として保存するのは職員の操作だけ（SR-03）

## Claude に渡すもの

- アレルギーの条件は「施設の避ける品目の一覧」だけを渡す。子どもの情報はそもそも持たない（NFR-SEC-05）
- 献立提案に渡す商品は、今週の掲載品のうち、おやつ対象で「使わない」「今週は使わない」でないものに絞る（NFR-COST-02）
- 避ける品目が1つでもあれば、アレルゲンが「不明」の商品は渡す前に候補から除く（SR-09）
- 03 §5 の判定が「入れられない」の商品（含む・含む可能性あり・不明）と、税込価格か入数が未入力の商品も、渡す前に除く（FR-MENU-07c。入れ替え案・`search_products` と同じ基準。biz-logic.md の候補の絞り込み）
- 予算に合わせる入れ替え案は、アプリが計算した候補だけを渡し、Claude には「どれが要望に合うか」の選択と説明だけをさせる（FR-MENU-30）
- 週の要望の読み取りと献立案は、1回の呼び出しでまとめて返させる（D-66）。要望が空欄なら、読み取りの部分を省いて献立だけを作らせる
- 商品照合の判定（Haiku）に回すのは、アプリのルールで決められなかった「迷うもの」だけ（完全一致・内容量違いは回さない。D-63）。1商品につき1回呼ぶ。1回の取り込みでの呼び出しの上限は設定で持つ（仮の値：30回）

## プロンプト

- プロンプトは `Prompts/` にまとめ、日本語で書く（NFR-MNT-03）。ファイルは EmbeddedResource にして読む（`dotnet publish` の成果物に確実に含めるため）
- 週の要望・チャット・重複の補足ルールの文章で、次のものを緩めさせない：アレルギーの条件、週の予算、重複ルール（FR-COND-05）の期間。そういう依頼が来たら、満たせない理由を説明させる（FR-MENU-23）
- 出欠（「○○くんは今日お休み」など）は献立に反映させない。常に施設の避ける品目すべてを条件にする（Q-13）
- チラシの読み取りは誤りがある前提で扱う（実際に「(乳)」を読み落とした例がある）。アレルゲン表記は書かれている品目だけを「含む」とし、書かれていない品目を「含まない」にしない

## 画像とログ

- チラシ・パッケージの画像は Claude に送るだけで、サーバーに保存しない。処理が終わったらメモリから破棄する
- ログに画像データ・子どもの情報・API キーを出さない
