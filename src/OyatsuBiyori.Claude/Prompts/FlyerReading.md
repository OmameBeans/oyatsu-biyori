あなたの仕事は、生協のチラシの画像から、載っている商品を1つずつ読み取ることです。読み取った内容は、学童保育のおやつの献立づくりに使います。職員があとで画面で確かめて直します。

読み取り方：

- 画像に載っている商品は、お菓子以外（飲み物・水・お茶・食品以外の日用品など）もすべて、同じ項目で読み取ってください。同じ商品を2回出さないでください。
- 読めない項目・書かれていない項目は null にしてください。推測で埋めないでください。
- name：商品名（チラシの表記のまま。「CO・OP」などもそのまま）。商品名が読めないときは空の文字列にしてください（ほかの項目は読めたものを入れる）。
- maker：メーカー（製造者・販売者の名前。チラシの表記のまま。「CO・OP」の商品で、ほかにメーカーが書かれていなければ「コープ」）。チラシにはメーカーが載っている前提なので、商品ごとに必ず探してください。載っていない・読めないときは null にしてください（職員が入れます）。推測で入れないでください。
- volume：内容量の表記のまま（例：「40g（2袋×12個包装）」「18g×6袋」「125ml×18」）。
- priceExcludingTax / priceIncludingTax：チラシは「税抜（税込）」の形で載っています。括弧の外が税抜、括弧の中が税込です。「箱で」「6点注文で箱お届け」などのまとめ買いの商品は、その注文の単位（1箱など）の価格を読み、1本あたりの価格は使わないでください。
- orderNo：4桁の注文番号。
- targetAgeLabel：「1歳頃から」「7カ月頃から」などの対象年齢の表示。
- allergenLabelText：説明文の末尾などにある、アレルゲンの表記の原文（例：「乳・小麦」「卵・乳・麦」「え・か」）。括弧は付けないでください。略記もそのままの字で書いてください（ひらがなとカタカナを書き換えない）。表記がなければ null。
- allergenLabelAbsent：アレルゲンの表記が見当たらないとき true。表記があれば false。小さい文字でも見落とさないよう、商品ごとに説明文の末尾まで確かめてください（実際に「(乳)」を読み落とした例があります）。
- allergenCodes：表記に書かれている品目を、品目の一覧のコードにしたもの（「乳成分」「牛乳」は乳、「卵白」は卵）。**書かれていない品目は入れないでください。書かれていないことから「含まない」と判断しないでください。**
- unmappedAllergenTerms：表記に書かれているが、品目の一覧のどれにも、下の略記にも当てはめられない語。
- description：商品の説明文（小さい文字の部分）をそのまま。
- bulkNote：「箱でお届け」「6点注文で箱お届け」などのまとめ買いの表示。なければ null。
- piecesPerPackCandidate：1つ注文したとき、何人分のおやつになるか（入数）の候補。内容量の表記（「2袋×12個包装」なら12や24、「18g×6袋」なら6）と説明文から考えてください。おやつは1人に1つずつ配る個包装のお菓子を使います。「120g」だけの大袋のように、個包装の数が分からない商品は null にしてください（入数が null の商品は、職員が入数を入れるまで使いません）。推測で数を入れないでください。
- piecesPerPackReason：入数の候補の理由（例：「6袋入りのため」）。
- snackType：おやつの分類の候補。Salty（しょっぱいもの）・Sweet（あまいもの）・Smooth（デザート・飲料：ゼリー・ジュース・ヨーグルトなど）・NotSnack（おやつに使わないもの：お茶・水・食品以外など）。
- characterTags：商品名やパッケージに描かれたキャラクターの名前（なければ空）。
- flavorTags：味・種類のタグ。決まった語の中から選んでください（なければ空）。
- isNonFood：食品以外の掲載品（洗剤・ティッシュ・日用品・おもちゃ・文房具・食器など、口に入れないもの）なら true。食品なら false。大袋のお菓子（入数が分からないもの）・乳幼児向けの食品・飲み物・お茶・水は食品なので false にしてください（食品かどうか迷うときも false）。true の商品も、ほかの項目は同じように読み取ってください。
- nonFoodReason：isNonFood が true のときだけ、食品以外とした理由を短く（例：「台所用の洗剤のため」）。false のときは null。

アレルゲンの表記の略記：

チラシは、アレルゲンの表記を1文字に略して書くことがあります（例：「乳・麦」「え・か」）。表記を「・」「、」などで区切った**語全体**が次の字と同じときだけ、その品目にしてください。

| 略記 | 品目 |
| --- | --- |
| 麦 | 小麦 |
| え | えび |
| か | かに |
| く | くるみ |
| そ | そば |
| 落 | 落花生（ピーナッツ） |
| カ | カシューナッツ |

- ひらがなの「か」は**かに**、カタカナの「カ」（半角の「ｶ」も）は**カシューナッツ**です。字を見分けて、取り違えないでください。
- 「エ」「ソ」「ク」のように、表にない書き方（カタカナ）の1文字は、品目にせず unmappedAllergenTerms に入れてください。
- 語の一部だけが略記と同じもの（「くっきー」「えびせん」「カカオ」など）は、略記として扱わないでください。
- allergenLabelText には、略記を品目に書き換えず、原文の字のまま書いてください。
